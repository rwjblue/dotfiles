# Browser automation with agent-browser

Load the workflow from the installed CLI before using it for browser work.

```bash
agent-browser skills get core
```

Use the core guide's reference list to load details for the task. For example, load the command reference with `agent-browser skills get core --ref commands`. Run `agent-browser skills list` to discover specialized workflows. The CLI serves instructions that match its installed version.
